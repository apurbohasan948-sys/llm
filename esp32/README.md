# PocketAI ESP32 Robot Controller Firmware (Future Architecture)

This directory is reserved for the future ESP32 robot firmware implementation.

## Design Constraints
- Hardware target: ESP32-S3 / ESP32 with Wi-Fi & BLE.
- Connects securely to the PocketAI Server gateway using robot-specific credentials generated by the Android application.
- Does not hold permanent third-party LLM secrets.
- Manages sensor telemetry, motor actuation, and audio I/O streaming.
